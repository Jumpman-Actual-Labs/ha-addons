# Jumpman Actual Labs Add-ons

Home Assistant add-ons by Jumpman Actual Labs. Add this repository once
(Settings > Add-ons > Add-on Store > ⋮ > Repositories):

```
https://github.com/Jumpman-Actual-Labs/ha-addons
```

then install whichever add-ons you want. Nothing installs until you pick it.

| Add-on | Description |
| --- | --- |
| [Cache](cache/DOCS.md) | Firearm, parts, ammunition, maintenance and range tracking |
| [Relay](relay/DOCS.md) | One chat for your Claude Pro and ChatGPT Plus subscriptions |
| [Garage](garage/DOCS.md) | Vehicles, fuel, maintenance and documents for your household |
| [Stash](stash/DOCS.md) | Household bills, income, budgets, savings and settlements |
| [Gains](gains/DOCS.md) | AI-assisted workout planning and tracking for your household |
| [Family Hustle](family_hustle/DOCS.md) | Family calendar, chores, allowance, meal planning and shopping list in one place |
## AI assistance

These add-ons were built with AI assistance (Anthropic's Claude and
OpenAI's ChatGPT). All code is reviewed and tested before release, but
please report any issues you run into.
